## 事件概述

Eli Bendersky 在其博客上发表了一篇短文，讨论一道流传已久的数学趣题：**给定恰好四个数字 2，允许使用任意数学运算，构造出任意指定的自然数**（不得引入其他数字）。

这道题的特点是"分层可玩"：小学生用加减乘除就能做出 1 到 6；中学生加上指数、阶乘后能覆盖更大范围；大学生甚至可以用 Gamma 函数、积分、连分数、组合算子、复数模长等手段继续扩张。文章最后给出了 Paul Dirac 的**通解**——一个对任意 n 都成立的嵌套平方根 + 双层对数构造，并且刚好只用到四个 2。

作者说明这个故事的来源是 Graham Farmelo 的传记《The Strangest Man: The Hidden Life of Paul Dirac, Quantum Genius》。原文还提到，这类消遣在 1920 年代曾是数学家们的爱好，直到 Dirac 给出通用解"把游戏玩坏了"。

## 关键技术点

### 1. 分层构造：工具越强，可表示集合越大

原文给出的初等例子：

```
1 = (2+2)/(2+2)
2 = 2/2 + 2/2
3 = 2·2 - 2/2
4 = 2+2+2-2
5 = 2·2 + 2/2
6 = 2·2·2 - 2
```

引入指数与阶乘后：

```
18   = 2^(2^2) + 2
28   = (2+2)! + 2 + 2
256  = (2+2)^(2+2)
65536 = 2^(2^(2^2))
```

再引入"把 22 视为两个 2 的合法组合"这类技巧：

```
26  = 22 + 2 + 2
11  = 22 / √(2+2)
444 = 222 · 2
```

原文提到 7 是出了名的难做，但只要允许 Gamma 函数就变得平凡（Γ(2) = 1）：

```
7 = Γ(2) + 2 + 2 + 2
```

作者还举了一个他最喜欢的复数例子：

```
12 = |2 + 2√(-2)|^2
```

（验算：2 + 2√2·i 的模平方为 4 + 8 = 12。）

### 2. Dirac 的通解：嵌套平方根 + 双层对数

核心恒等式是把"重复开平方"翻译成 2 的负指数：

```
√2            = 2^(1/2)  = 2^(2^-1)
√√2           = 2^(1/4)  = 2^(2^-2)
√√√2          = 2^(1/8)  = 2^(2^-3)
```

即开 n 次平方根得到 2^(2^(-n))。对其取一次以 2 为底的对数，得到 2^(-n)；再取一次对数，得到 -n。于是：

```
n = -log₂( log₂( √√…√2 ) )     // 嵌套 n 层
```

### 3. 补足"四个 2"这一步

上面的通式只用了**三个** 2。作者沿用原文的思路指出：因为 2 = √(2+2)，可以把其中任意一个单独的 2 替换成这个等价表达式，从而凑满四个：

```
n = -log_{√(2+2)}( log₂( √√…√2 ) )
```

原文以 7 为例，写成七层嵌套平方根的形式。文中强调：式子里的 n 并不真的出现在表达式中，它只是一个"数平方根层数"的辅助记号。作者的评价是——这种做法或许会被认为在"作弊"，但它确实符合这道题的规则字面；而且用到的都是基础、初等的数学运算，唯一真正的挑战是把那些根号画清楚。

## 对数据科学或 AI Agent 落地的意义

需要说明的是：**原文是一篇纯数学趣题文章，完全没有涉及数据科学或 AI Agent**。以下是我基于其结构做的类比性延伸，不属于原文内容。

- **"允许哪些算子"直接决定解空间**。这道题的难度完全由算子集合决定：只有四则运算时 7 做不出来，加上 Gamma 函数后一行搞定。这和应用侧的工具体系设计是同构的——Agent 可用工具集的粒度与强度，决定了它能"表达"出哪些解，也决定了搜索的难度和结果的可审计性。
- **构造性证明 vs 存在性证明**。Dirac 给出的是可机械展开的构造（给定 n 就能写出表达式），而不只是"存在性"论证。在自动推理、符号计算、程序合成中，可展开、可验证的构造才是可交付物；一句"存在解"对下游流水线没有价值。
- **表达式即程序**。这类谜题的产物是一个形式化表达式，天然可被解析、求值与校验——这与 symbolic regression、DSL 式程序搜索的形态一致，也提示了"生成 + 数值验证"这种闭环评估方式的可行性。
- **语义等价但语法不同的改写**。把基底 2 换成 √(2+2)，数学上完全相同，只是"计数"变了。这类改写正是形式化系统里最容易引发争议的地方，也提醒我们：评估指标如果只看表面形式，很容易被等价变换绕过。

## 我的技术点评

这篇文章最有意思的地方不是公式，而是**规则边界的模糊性**。原文从头到尾没有严格定义"允许的数学运算"到底是什么集合：Gamma 函数算不算？积分算不算？把 22 当作两个 2 的拼接算不算？作者自己也承认，用 Γ(2) = 1 和用 √(2+2) 替换单个 2，都可能"被视为作弊，但符合规则的字面"。
