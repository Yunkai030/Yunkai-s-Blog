# OpenAI 与 Anthropic 掀起 LLM 价格战：数月内降价最高 80%，背后逻辑是什么？

## 一、事件概述

2026 年 6 月至 9 月，OpenAI 与 Anthropic 在短短三个月内密集发布新模型并大幅调价。根据 Max Woolf 的博客文章统计，从 GPT-5.6 系列发布到 GPT-6.1 Sol，主流 LLM 的使用成本出现"断崖式下跌"。原文所有价格单位均为 **输入价格 / 输出价格 / 缓存读取价格（每百万 Token，MTok）**。

原文整理的关键时间线如下：

- **2026-06-26**：OpenAI 发布 GPT-5.6 Sol（$5 / $30 / $0.50）与面向低价场景的小模型 GPT-5.6 Luna（$1 / $6 / $0.10），另有一个中间档 Terra 模型，但原文称"少有人关注"。
- **2026-06-30**：Anthropic 发布 Claude Sonnet 5，宣称接近 Opus 系列，但反馈"褒贬不一"，发布价为 $2 / $10 / $0.20，起初声明为临时价格。
- **2026-07-24**：Anthropic 发布 Claude Opus 5，定价 $5 / $25 / $0.50，与 GPT-5.6 Sol 相近。
- **2026-07-30**：OpenAI 将 GPT-5.6 Luna 降价 **80%**，至 $0.20 / $1.20 / $0.02。
- **2026-08-10**：Anthropic 宣布 Sonnet 5 的临时发布价转为永久价格。
- **2026-08-21**：OpenAI 将 GPT-5.6 Sol 降价约 **20%** 至 $4 / $20 / $0.40，但仅限未来三个月。
- **2026-09-01**：Anthropic 发布 Fable 5.1，定价 $10 / $50 / $0.25。相比 6 月的 Fable 5（$10 / $50 / $1），基准测试全面更优，同时缓存读取成本下降 **75%**。
- **2026-09-03**：OpenAI 发布 GPT-6 Astra，规模与 Fable 5.1 相近，定价 $10 / $50 / $1，但缓存读取价格更高。
- **2026-09-22**：OpenAI 发布 GPT-6 Sol（$2 / $10 / $0.20）与 GPT-6 Luna（$0.10 / $0.50 / $0.01），输入输出价格相对此前版本减半。**同日**，Anthropic 发布 Claude Opus 5.5（$4 / $20 / $0.20），官方明确表示"Opus 5.5 服务所需算力低于 Opus 5，定价反映了这一点"，综合成本下降 **40%–60%**。
- **2026-09-29**：由于 GPT-6 Sol 性能表现不佳，OpenAI 在一周后发布 GPT-6.1 Sol，性能与 Astra 相当，并将缓存读取价格再砍半至 $2 / $10 / $0.10，与 Anthropic 的"输入价格 5%"缓存定价对齐，使该模型家族累计便宜 **75%**。

原文还引用了 Vercel AI 模型网关的数据：每 Token 成本已降至 2026 年 4 月水平的 **43.3%**，但由于模型能力提升快于价格下降，总体支出反而在增加。
