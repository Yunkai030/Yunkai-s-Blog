## 论文概述

arXiv 论文 **《EarthRecord: From Pixels to Land Change with Multimodal Agents over Four Decades of Satellite Imagery》** 提出了一个面向多模态 Agent 的遥感土地变化分析基准 **EarthRecord**。论文由 Haoran Zhang、Huizhen Sun、Hanbin Wen、Jie Leng、Jiaxin Zhu、Zhaohua Sun 完成，提交于 2026 年 11 月 6 日，归类为 cs.AI，并涉及 cs.CV。

论文指出，多模态 Agent 已经能够借助工具完成复杂数据分析，但它们能否把数十年的卫星影像转化为可靠的土地变化分析，仍缺乏系统评测。现有基准通常基于经过筛选的图像提问，或直接给 Agent 提供预处理后的输入，遗漏了真实地球观测分析开始的地方：原始多传感器档案。

EarthRecord 因此构建在 **56 个站点的原始记录**上，覆盖四十年跨度的 Landsat、MODIS、VIIRS 和 Sentinel-2 数据。关键之处在于，云掩膜和跨传感器协调并没有替 Agent 完成，而是留给 Agent 自己处理。基准包含 **238 个土地变化问题**，分布在 **十类分析任务**中，评分参考来自全球产品中的保留参考、方法间一致性以及视觉解译。论文还设置了两类控制实验：**closed book** 移除影像记录，用于测试答案是否依赖先验知识；**instrument pairs** 改动其中一颗卫星的数据，而地面真实情况不变，用于测试 Agent 是否真正跟随像素证据。

对十二个多模态 Agent 的评测显示，领先 Agent 能端到端完成大多数分析，但在答案需要从影像进行映射时仍会失手。进一步分析表明，影像记录让答案从先验知识转向像素，但尚未真正转向地面变化：当一颗卫星的数据被改动时，一半原本正确的答案会跟随改动而变化。

## 关键技术点

**1. 以原始多传感器档案作为评测起点**

EarthRecord 的核心设计不是给 Agent 一张干净图片或一个预处理好的时间序列，而是提供跨四十年、多传感器的原始记录。Agent 需要自行面对云掩膜、跨传感器协调等实际数据工程问题。这使评测对象从“单轮视觉问答”扩展为“长流程遥感分析”。

**2. 长时间跨度与异构传感器并存**

Landsat、MODIS、VIIRS 和 Sentinel-2 在空间分辨率、时间频率、光谱配置和覆盖时期上并不一致。基准要求 Agent 在异构数据之间建立可比性。论文摘要没有展开具体的协调算法和任务清单，相关细节原文未说明。

**3. 多任务土地变化问题集**

238 个问题覆盖十类分析任务，具体任务定义与评分公式在当前摘要范围内未说明。评分并非只依赖单一标签，而是结合全球产品中的保留参考、不同方法之间的一致性
