## 事件概述

OpenAI 于 2026 年 9 月 29 日发布 DevDay 2026 Recap，官方称这是"迄今规模最大"的一届 DevDay，围绕 ChatGPT、Codex、模型以及"全新的 AI 协作方式"发布了 20 多项公告。

从原文的组织方式看，这次发布的主线有三条：

1. **Agent 从"被调用"走向"承担持续职责"**：推出 Dots（常驻在线 Agent）以及带计算机使用能力的 Agents API。
2. **人与 AI 协作界面的重构**：把 ChatGPT 开放为一个"共享界面"，让人类与 Agent 在其中协作，并允许开发者直接向总计 12 亿周活用户发布原生体验。
3. **模型梯队与工程化基础设施的补齐**：GPT-6.1 Sol、Ultrafast 速度层、Codex 云端能力、私有化与安全方案。

需要说明的是，原文正文在 "ChatGPT Space" 一节处即被截断，该产品的完整说明以及可能存在的其他公告，**原文未说明**。

## 关键技术点

### 模型与推理速度

**GPT-6.1 Sol**：GPT-6 Sol 的重大升级，原文强调其在 agentic coding（智能体编程）、计算机使用（computer use）和专业工作上的表现"异常强劲"。定位上，它以 Astra 标准输入与输出 token 价格的五分之一，向所有用户提供"接近 Astra 的智能"，目标是让开发者在同一预算内执行更复杂的工作流。开放范围：所有 API、Plus、Pro、Business、Enterprise、Edu 用户。

**Ultrafast**：面向对速度最敏感负载的高级速度层。原文给出的数字是 Codex 中最高 8 倍 token 生成加速（300 tokens/秒），API 中最高 6 倍。GPT-6 Astra Ultrafast 已在 API、ChatGPT Work 和 Codex（Pro 500 与 Enterprise 计划）上线；GPT-6.1 Sol Ultrafast 标注为"即将推出"。

### Agent 能力：Dots 与 Agents API

**Dots**：被描述为"能力出众的常驻在线 Agent"（always-on agents），会逐步了解对你重要的事情，持续替你工作，从而把重要工作从你的待办中拿走。可用范围：符合条件的市场中的 Pro 与 Business Premium；Enterprise、Edu、Healthcare 用户需由工作区管理员启用后试用 Beta，**默认关闭**。

**Agents API 支持 Computer use**：开发者可以构建能够与软件交互以完成任务的 Agent。同时把 Codex 的多 Agent 能力、工具搜索、工具调用和上下文压缩（context compaction）带入应用层，底层基础设施由 OpenAI 运行。

**Bedrock Managed Agents, powered by OpenAI**：与 Amazon 合作，将 Agents API 的核心能力加上定制化，原生运行在 AWS 并集成 AWS 资源，使 OpenAI Agent 可以完全运行在 AWS 内。

**Decisions API**：把 Luna 的智能聚焦到一组用户定义的问题上，且这些问题的答案是有限、预定义的，从而实现实时决策。开发者以文本或图像提供上下文，返回结果可用于内容分类、请求路由或选择 Agent 的下一步动作。当前为有限预览，更广泛的发布计划在"接下来的几天"内。

### 开发者工具：Codex 与 API

- **Codex in the cloud**：可在电脑上、从手机远程、或在云端从任意设备运行 Codex；可复用的开发环境帮助任务快速启动，并让团队共享带审批设置与权限的配置。覆盖 Plus、Pro、Business、Healthcare、Education、Enterprise。
- **新版 Codex CLI**：支持用语音启动和引导任务；新增 `/agents` 视图，便于委派工作和同时追踪多个任务；改进了编辑提示词、恢复会话和使用 worktree 的日常流程，终端 UI 更清爽。所有计划可用。
- **Code Review**：ChatGPT 桌面应用中的新代码审查体验，可阅读摘要、浏览 diff，并在向 GitHub PR 或 GitLab MR 提交反馈前先向 Codex 询问潜在问题。自动审查可让你不在时由 Codex 在云端先做一轮。所有计划可用。
- **Codex Security Cloud**：面向防御方，可按需或按计划扫描整个 GitHub
